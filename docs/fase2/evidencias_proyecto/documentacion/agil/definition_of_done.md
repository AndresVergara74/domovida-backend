# Definition of Done (DoD) — DomoVida

Criterio común del proyecto, según la Guía de apoyo del estudiante (sección 5.4) y la Guía 1.5 (sección 5.7).

Una historia de usuario pasa a **Terminada** solo cuando cumple **todas** estas condiciones:

- [ ] Está implementada.
- [ ] Cumple sus criterios de aceptación (formato Dado / Cuando / Entonces).
- [ ] El código está integrado en la rama principal (`main`) del repositorio.
- [ ] Las pruebas correspondientes se ejecutaron y pasan (PU, PI, PR, PS).
- [ ] La documentación necesaria está actualizada (README, manual técnico).
- [ ] No tiene errores críticos conocidos.
- [ ] Está disponible en el entorno definido (contenedores Docker: `docker compose up --build`).

Esta DoD complementa los criterios técnicos del backend, frontend, base de datos, Docker y AWS definidos en la sección 5.2 de la Guía 1.5.
