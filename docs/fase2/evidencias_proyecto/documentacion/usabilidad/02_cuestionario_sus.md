# Cuestionario SUS (System Usability Scale) · versión en español

Texto para crear el formulario en **Google Forms**. Cada pregunta es de **escala lineal de 1 a 5**:
1 = Totalmente en desacuerdo · 5 = Totalmente de acuerdo. Todas obligatorias.

## Sección 1 · Consentimiento
> Esta encuesta es parte del proyecto de título DomoVida (Duoc UC). Su participación es voluntaria y anónima: no se le pedirá su nombre, RUT ni datos de contacto, y puede retirarse en cualquier momento. Las respuestas se usan solo para evaluar el sistema.

- ¿Acepta participar? (Sí / No) — *si responde No, el formulario termina*

## Sección 2 · Datos generales (sin datos personales)
- Código de participante (lo entrega el facilitador): P01, P02…
- Rango de edad: 18–29 · 30–44 · 45–59 · 60 o más
- Tipo de cuidador: familiar · profesional (técnico/a, enfermero/a u otro) · ex cuidador/a
- ¿Con qué frecuencia usa aplicaciones en el celular o computador? Diaria · Semanal · Pocas veces

## Sección 3 · Escala SUS (Brooke, 1996)
1. Creo que me gustaría usar este sistema con frecuencia.
2. Encontré el sistema innecesariamente complejo.
3. Pensé que el sistema era fácil de usar.
4. Creo que necesitaría el apoyo de una persona con conocimientos técnicos para poder usar este sistema.
5. Encontré que las distintas funciones del sistema estaban bien integradas.
6. Pensé que había demasiada inconsistencia en este sistema.
7. Imagino que la mayoría de las personas aprendería a usar este sistema muy rápidamente.
8. Encontré el sistema muy engorroso de usar.
9. Me sentí muy seguro/a usando el sistema.
10. Necesité aprender muchas cosas antes de poder empezar a usar este sistema.

## Sección 4 · Comentarios (opcional)
- ¿Qué fue lo más fácil de usar?
- ¿Qué cambiaría o mejoraría?

## Cálculo del puntaje (lo hace la planilla 03_resultados_sus.xlsx)
- Preguntas impares (1, 3, 5, 7, 9): respuesta − 1
- Preguntas pares (2, 4, 6, 8, 10): 5 − respuesta
- Puntaje SUS = suma de los 10 valores × 2,5 (de 0 a 100)
